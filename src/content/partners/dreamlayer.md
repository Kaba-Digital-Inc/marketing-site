## How we work with DreamLayer.io

DreamLayer.io is an AI image agent for characters, environments, items, and UI, with an API, a CLI, and an MCP server. It sponsors ClawBuilders, the agent builder community we run.

**The Game Jam.** ClawBuilders and DreamLayer.io ran the DreamLayer.io Game Jam, a live agent tournament where builders competed for a prize pool, with free API credits to get started. It is an example of how sponsors and builders meet through ClawBuilders: a real tool, a real task, and people building with it the same evening.
